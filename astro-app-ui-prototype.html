Main

The calibration banner names the camera, the missing item, the consequence and the cost — FR-4.0.4.2. It has a dismiss, and it sits below the start button rather than above it, so it can never read as a gate.

Unstacked sessions show Stack now as the badge, not a status word. The badge is the action.

Session setup

One line carries the solve; Show work opens the full derivation including the options that lost and why. Same screen, one tap deeper — no advanced mode.

Common area at end is stated during planning, in amber, before the user commits 30 minutes to a frame that will lose a quarter of itself.

Capturing

The ring is one tick per planned frame, ordered clockwise from the top: filled for kept, hollow amber for rejected, faint for not yet taken. Session progress, quality history and the clustering of failures in a single object readable from two metres away in the dark.

The preview defaults to the running stack, not the last sub — it visibly cleans up as frames accumulate, which is the reward loop. A raw 12s sub is a near-black rectangle, so the preview is autostretched and labelled as such.

The end button says End & take darks, so the last required step is never a surprise.
